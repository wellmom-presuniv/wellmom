# WellMom

Maternal health mobile app — edukasi gizi kehamilan & deteksi dini risiko, kolaborasi FCS × FKPU President University.

## Struktur Repo

```
wellmom/
├── mobile/    React Native + Expo + NativeWind — app untuk ibu hamil (Arka)
├── backend/   FastAPI + PostgreSQL — API & database (Alek)
├── cms/       React + TypeScript + Tailwind + shadcn/ui — admin tool untuk kelola konten klinis (Thoriq)
└── docs/      Dokumen pendukung (BPD, ERD/DFD, Jira reference) — versi utama tetap di Notion, ini cuma salinan untuk arsip
```

Tiap folder punya README sendiri dengan instruksi setup spesifik stack-nya.
